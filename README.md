# HAPP Browser

Firefox-расширение для маршрутизации трафика браузера через SOCKS5-прокси HAPP Desktop. Остальные приложения операционной системы не должны менять свой маршрут.

## Текущий этап — 0.1.0

- Базовый интерфейс HAPP Browser.
- Настройка адреса и порта SOCKS5.
- Переключение прокси Firefox через WebExtensions API.
- SOCKS5 и DNS через прокси.
- Сохранение исходной конфигурации Firefox перед включением.
- Восстановление предыдущей конфигурации при отключении.
- Защита от перезаписи настроек, которые успел изменить пользователь или другое расширение.
- На текущем этапе разрешён только loopback: `127.0.0.1`, `localhost`, `::1`.
- Профили и состояние подключения HAPP Desktop пока не считываются и не управляются.

## Важные ограничения

Официальная инструкция HAPP по LAN-подключениям описывает адрес текущего IP и SOCKS5-порт для доступа из локальной сети. Она не подтверждает, что конкретная установка HAPP предоставляет loopback listener. Не включайте LAN Connections и не вводите адрес из локальной сети до отдельной проверки безопасности.

Для изменения настроек прокси Firefox требует разрешить расширению работу в приватных окнах. Если Firefox откажет в доступе, откройте `about:addons` → HAPP Browser → Разрешения и разрешите работу в приватных окнах.

## Локальная установка для теста

1. Скачайте ZIP ветки `research/happ-local-proxy` и распакуйте его.
2. Откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите **Загрузить временное дополнение…**.
4. Выберите `manifest.json` в распакованной папке.
5. Откройте popup HAPP Browser.

Временное дополнение может потребоваться загрузить снова после перезапуска Firefox.

## Проверка после ручной настройки HAPP

1. Убедитесь, что локальный SOCKS5 listener HAPP доступен на loopback и запишите фактический порт.
2. Введите адрес `127.0.0.1` и этот порт в расширение.
3. Нажмите **Подключить Firefox**.
4. Проверьте внешний IP в Firefox.
5. Проверьте внешний IP в другом приложении — он должен остаться прямым.
6. Нажмите **Отключить прокси** и убедитесь, что исходные настройки Firefox восстановились.

Если HAPP не предоставляет SOCKS5 на loopback, не включайте LAN-доступ ради теста без отдельной оценки сетевой безопасности.
