# HAPP Browser

Независимое Firefox-расширение для диагностики VPN-подключения и сетевых утечек непосредственно в браузере.

## Текущий этап — 0.4.0 preview

Реализовано:
- Проверка внешнего IP-адреса и страны через `ipwho.is` и отдельные IPv4/IPv6 endpoint'ы `api4.ipify.org` и `api6.ipify.org`.
- Сохранение последнего результата IP-проверки локально в Firefox.
- DNS-диагностика через API `dnsleak.dev`: одноразовые имена, запросы из Firefox, список резолверов, замеченных авторитетным DNS-сервером.
- WebRTC-диагностика через ICE gathering и публичный STUN-сервер: сбор ICE-кандидатов, отображение типов и протоколов, сравнение публичных ICE-адресов с контрольным IP выхода Firefox.
- Локальное сохранение последних результатов DNS- и WebRTC-проверок.

Пока не реализовано:
- Проверка IPv6 как отдельный сетевой тест.
- Проверка доступности выбранных сайтов.
- История проверок с просмотром прошлых результатов.

## Дополнительные проверки и история

- IPv4/IPv6: отдельные запросы к IPv4- и IPv6-endpoint'ам ipify. Доступность IPv6 не объявляется утечкой автоматически.
- Website Reachability: проверка сетевого ответа для введённого HTTP/HTTPS-адреса. Разрешение Firefox запрашивается отдельно для каждого домена. Из-за ограничений CORS расширение не читает HTTP-статус и содержимое ответа.
- История: последние 50 результатов IP, DNS, WebRTC, IPv6 и проверок сайтов хранятся локально в Firefox. Историю можно очистить в popup.

## Ограничения WebRTC-проверки

WebRTC-тест использует STUN-сервер Google `stun:stun.l.google.com:19302`. Доступность STUN зависит от сети, VPN, firewall и настроек Firefox. Если ICE gathering не завершился или не удалось получить контрольный IP, результат считается неопределённым. Отсутствие несовпадений публичных ICE-адресов не является абсолютной гарантией отсутствия утечек. Локальные host-кандидаты сами по себе не доказывают раскрытие публичного IP.

## Приватность

Для получения внешнего IP и страны расширение отправляет запрос к стороннему сервису `ipwho.is`. IPv4/IPv6-тесты отдельно обращаются к `api4.ipify.org` и `api6.ipify.org`. Эти сервисы видят IP-адрес, с которого поступают запросы. Результаты сохраняются локально в Firefox.

DNS-проверка использует API `dnsleak.dev`: расширение запрашивает тестовую сессию, разрешает одноразовые имена и получает список DNS-резолверов, увиденных авторитетным сервером. Сервис видит IP клиента и DNS-резолверы; результаты хранятся в памяти около десяти минут. Последний отчёт хранится локально в Firefox. Перед запуском ознакомьтесь с [политикой конфиденциальности сервиса](https://dnsleak.dev/privacy).

WebRTC-проверка устанавливает STUN-соединение с Google для сбора ICE-кандидатов. STUN-сервер видит сетевой адрес, с которого поступает STUN-трафик. Последний результат хранится локально в Firefox.

## Установка для разработки

1. Скачайте ZIP основной ветки `main` и распакуйте.
2. Откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите **Загрузить временное дополнение…**.
4. Выберите `manifest.json`.
5. Откройте popup расширения и запустите нужную проверку.
