# HAPP Browser

Независимое Firefox-расширение для диагностики VPN-подключения и сетевых утечек непосредственно в браузере.

## Текущий этап — 0.2.0 preview

Реализовано на текущем этапе:
- Проверка внешнего IP-адреса.
- Определение страны выхода в интернет.
- Отображение ошибок и тайм-аута запроса.
- Сохранение последнего результата проверки локально в хранилище расширения.

Пока не реализовано:
- DNS leak test через API `dnsleak.dev`: генерация уникальных имён, DNS-запросы из Firefox, получение списка наблюдавшихся резолверов и локальное сохранение последнего результата.
- WebRTC leak test.
- Проверка IPv6.
- Проверка доступности выбранных сайтов.
- История проверок с просмотром прошлых результатов.

## Приватность

Для получения внешнего IP и страны расширение отправляет запрос к стороннему сервису `ipwho.is`. Сервис видит IP-адрес, с которого поступает запрос. Результат сохраняется локально в Firefox. Не запускайте проверку, если не согласны с передачей запроса этому сервису.

Получение IP и страны не является доказательством отсутствия DNS, WebRTC или IPv6-утечек.

DNS-проверка использует API `dnsleak.dev`: расширение запрашивает тестовую сессию, разрешает одноразовые имена и получает список DNS-резолверов, увиденных авторитетным сервером. Сервис видит IP клиента и DNS-резолверы; результаты хранятся в памяти около десяти минут. Последний отчёт хранится локально в Firefox. Результат — наблюдение конкретных запросов, а не гарантия отсутствия утечек. Перед запуском ознакомьтесь с [политикой конфиденциальности сервиса](https://dnsleak.dev/privacy).

## Установка для разработки

1. Скачайте ZIP ветки `feature/vpn-diagnostics` и распакуйте.
2. Откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите **Загрузить временное дополнение…**.
4. Выберите `manifest.json`.
5. Откройте popup расширения и нажмите **Проверить подключение**.
