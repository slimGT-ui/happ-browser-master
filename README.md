# HAPP Browser

Браузерное расширение для Firefox, которое в дальнейшем позволит управлять HAPP Desktop непосредственно из браузера.

## Текущий этап

Сейчас реализована только начальная основа расширения:

- Manifest V3 для Firefox.
- Всплывающее окно по нажатию на иконку расширения.
- Базовый тёмный интерфейс с фиолетовыми акцентами.
- Минимальные разрешения: расширение пока не запрашивает доступ к вкладкам, сайтам или хранилищу.

## Локальный запуск в Firefox

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **Загрузить временное дополнение…**.
3. Выберите файл `manifest.json` в корне проекта.
4. Нажмите на иконку HAPP Browser на панели Firefox.

На этом этапе подключение к HAPP Desktop и управление VPN ещё не реализованы.
